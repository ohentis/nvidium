# Nvidium



Nvidium is an alternate rendering backing for sodium, it uses cutting edge nvidia features to render huge amounts of
terrain geometry at very playable framerates. This is a port of Nvidium for 1.7.10. Currently heavily in alpha. Use at your own risk.

### Requires Angelica 2.0.0-alpha19, lwjgl3ify 2.1.18 and an nvidia gtx 1600 series or newer to run (turing+ architecture)

## Incompatibilities
 - Fluxloader
